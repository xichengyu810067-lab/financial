# 里程碑 3：三大報表 — 規格

討論日期：2026-10-23。完成定義：改一筆交易，三張報表立即更新；資產 = 負債 + 權益、期初現金 + 淨現金流量 = 期末現金兩個檢核永遠成立。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 期間選擇 | 月／季／年快速選項（本月、上月、本季、上季、今年、去年）+ 自訂起迄日；資產負債表以區間結束日為「截至日」 |
| 損益表附加欄位 | 上期比較欄（金額與變化 %）、佔總收入比例、子類別預設展開（可收合）、選「年」時多一張 12 個月的月度小表 |
| 下鑽方式 | 點報表任一列，從右側滑出該科目在該期間的交易明細面板，可直接點交易進入編輯 |
| 現金流量表 | 營業／投資／融資三活動，每類底下再列對方科目 |

## 期間與網址

- 網址：`/reports?tab=income|balance|cashflow&preset=month|quarter|year|custom&from=YYYY-MM-DD&to=YYYY-MM-DD`，預設 `tab=income`、本月。
- 期間選擇器：下拉快速選項 + 「‹ ›」依目前長度往前後移（月→上下月、季→上下季、年→前後年、自訂→同天數）+ 自訂時顯示起迄日欄位。
- **上期** = 同長度的前一段：月→上月、季→上季、年→去年、自訂→往前推同天數。
- 資產負債表顯示「期末（to）」「期初（from 的前一天）」「變化」三欄。

## 損益表 `tab=income`

- 資料來源：`report_income_statement(p_ledger, p_from, p_to)`，回傳每個收入／費用類別在期間內的金額（子類別各自一列）；前端把父類別彙總為「自身 + 子類別」。
- 版面：收入區（各類別、合計）→ 費用區（各類別、合計）→ 淨利。
- 欄位：類別、本期、佔收入 %（以本期總收入為分母；收入為 0 時顯示「—」）、上期、變化（金額與 %，上期為 0 時只顯示金額）。
- 子類別縮排顯示、預設展開，父類別列可收合。
- 只列有金額的類別（本期或上期任一不為 0）。
- 選「年」時，下方多一張月度小表：月份、收入、支出、淨利，資料來源 `monthly_summary(p_ledger, p_from, p_to)`。
- 下鑽：點類別列 → 明細面板列出該類別（含子類別）在期間內的交易。

## 資產負債表 `tab=balance`

- 資料來源：`report_balance_sheet(p_ledger, p_as_of)`，回傳每個資產／負債／權益帳戶截至該日的餘額，外加一列「累積損益」（開帳以來到截至日的收入 − 費用）。
- 版面：資產（各帳戶、合計）→ 負債（各帳戶、合計）→ 權益（期初餘額、累積損益、合計）→ 檢核列「資產 − 負債 − 權益 = 0」打勾 → 淨值（資產 − 負債）。
- 欄位：帳戶、期末、期初、變化。
- 封存帳戶若餘額不為 0 仍列出並標示「已封存」；餘額為 0 的封存帳戶不列。
- 下鑽：點帳戶列 → 明細面板列出該帳戶在期間內（期初次日到期末）的交易。

## 現金流量表 `tab=cashflow`

- 「現金及等價物」= 資產帳戶中子類型為現金、銀行、電子支付者。
- 資料來源：`report_cash_flow(p_ledger, p_from, p_to)`，回傳：
  - 期初現金（from 前一天的現金帳戶餘額合計）、期末現金（to 當天）
  - 每一列：活動（營業／投資／融資）、對方科目、流入、流出
- 分類規則（看每筆交易中現金帳戶的對方科目）：
  - 對方是收入／費用類別 → **營業活動**
  - 對方是非現金的資產帳戶（投資、其他資產）→ **投資活動**
  - 對方是負債或權益（信用卡還款、貸款、期初餘額設定）→ **融資活動**
  - 兩邊都是現金帳戶的轉帳 → 不列（內部移轉）
  - 信用卡刷卡不動到現金，不出現；還卡費那天才是融資活動的流出
- 版面：營業活動（各項、小計）→ 投資活動 → 融資活動 → 本期淨現金流量 → 期初現金 → 期末現金 → 檢核列「期初 + 淨流量 = 期末」打勾。
- 下鑽：點對方科目列 → 明細面板列出該科目與現金帳戶之間在期間內的交易。

## 明細面板（下鑽）

- 右側滑出，標題為科目名稱與期間，列表樣式同交易頁（日期分組、圖示、金額），底部顯示合計。
- 點任一筆 → 以既有的記帳面板（`EntrySheet`）開啟編輯；儲存或刪除後明細與報表一起重算。
- 資料：查詢期間內的交易（`entries` 依日期範圍）後在前端依科目篩選；同一份查詢給三張報表的明細共用。

## 資料庫變更（新 migration）

- `report_income_statement(p_ledger uuid, p_from date, p_to date)`：每個收入／費用類別的期間金額（收入 = 貸 − 借，費用 = 借 − 貸）。
- `report_balance_sheet(p_ledger uuid, p_as_of date)`：每個資產／負債／權益帳戶截至日餘額（依正常餘額方向），外加「累積損益」列。
- `report_cash_flow(p_ledger uuid, p_from date, p_to date)`：期初／期末現金與各活動列；多行分錄依金額比例分攤到各對方科目（目前交易都是兩行，結果精確）。
- `monthly_summary(p_ledger uuid, p_from date, p_to date)`：每月收入、支出、淨利（儀表板也會用）。
- 全部 `security invoker`、`set search_path = ''`，只授權給 `authenticated`。

## 前端

- `src/lib/ledger/period.ts`：期間預設值、往前後移、上期計算（純函式，Vitest）。
- `src/lib/ledger/reports.ts`：四個查詢 hooks，查詢鍵 `['reports', ledgerId, 報表名, from, to]`；`entries.ts` 寫入後一併 invalidate `['reports', ledgerId]`。
- `src/app/(app)/reports/`：`reports-view.tsx`（分頁與網址同步）、`period-picker.tsx`、`income-statement.tsx`、`balance-sheet.tsx`、`cash-flow.tsx`、`monthly-table.tsx`、`detail-sheet.tsx`、共用的 `report-table.tsx`（列、縮排、合計、檢核列）。
- 金額顯示沿用 `formatTWD`；百分比取到小數一位；變化為負用紅色、正用綠色（支出欄位反向：支出減少是好事，用中性色標示即可，不做顏色判斷）。

## 驗收

- Vitest：期間工具（各預設值的起迄、上期、往前後移、跨年）。
- SQL rollback 測試：建立含期初餘額、收入、支出、信用卡刷卡與還款、投資轉入、現金間轉帳的情境，驗證損益表淨利、資產負債表平衡檢核、現金流量表三活動分類與期初 + 淨流量 = 期末、月度摘要。
- 瀏覽器：三張報表數字與帳戶頁一致；改一筆交易後三表即時更新；期間切換與網址；年度檢視顯示月度小表；下鑽面板可開啟並編輯；兩個檢核列打勾。
- lint／test／build、CI、正式站驗收。
