# 里程碑 2：記帳 — 規格

討論日期：2026-10-23。完成定義：能完整記一個月的帳，分錄永遠平衡，帳戶餘額即時正確。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 記帳入口 | 全站固定的「記一筆」按鈕（桌機右下角、手機底部置中），點了從側邊滑出表單面板，存完可直接再記下一筆 |
| 金額輸入 | 內建小算式：可直接打 `120+35`、`300*2`、`(80+20)/2`，即時顯示結果 |
| 交易清單 | 月份切換 + 當月收支摘要 + 依日期分組，每天一組帶小計 |
| 輔助功能 | 「再記一筆」連續輸入、備註關鍵字搜尋、複製上一筆、批次刪除 |

## 記帳表單

- **種類**：支出（預設）／收入／轉帳，三個大按鈕切換。
- **金額**：文字欄位（手機跳數字鍵盤），接受 `0-9 . + - * / × ÷ ( )` 與空白；輸入時即時顯示「= 155」，算式錯誤或結果 ≤ 0 顯示提示；儲存時取結果，四捨五入到兩位小數。
- **日期**：預設今天，旁邊有「今天」「昨天」快捷。
- **帳戶**：只列未封存的資產／負債帳戶，顯示圖示與目前餘額。
  - 支出：「從哪個帳戶付」（信用卡消費就是選信用卡）
  - 收入：「存入哪個帳戶」
  - 轉帳：「從」「到」兩個，不可相同（還卡費 = 銀行 → 信用卡）
- **類別**：支出列費用類別、收入列收入類別；依父類別分組，父類別本身也可選；顯示圖示；封存的不列，但編輯舊交易時若該類別已封存仍顯示該筆原本的類別。
- **備註**：選填，最多 100 字。
- **分錄預覽**：表單底部即時顯示 `posting.ts` 產生的分錄，例如「借 飲食 150 / 貸 現金 150」。
- **儲存**：呼叫 `save_entry`，成功後 toast；「儲存並再記一筆」保留日期與帳戶、清空金額、類別、備註並把游標放回金額。
- **記住習慣**：下次開啟面板預設日期為今天、帳戶為上次使用的（存瀏覽器 localStorage，以帳本為鍵）。
- **編輯**：同一表單載入既有值，底部多「刪除」按鈕（需確認）。
- **複製**：從交易列操作，帶入種類、帳戶、類別、備註、金額，日期改為今天，以新增模式開啟。
- **期初餘額交易**（`kind = opening`）不在清單顯示，也不能從表單編輯，統一在帳戶頁管理。

## 交易清單 `/transactions`

- **月份切換**：`‹ 2026 年 10 月 ›`，點中間可直接選月份；預設本月；月份記在網址 `?month=2026-10`，重新整理或分享都保留。
- **摘要卡**：收入、支出、結餘（收入 − 支出）；轉帳不計入。
- **篩選列**：種類（全部／支出／收入／轉帳）、帳戶、類別、備註關鍵字（即時過濾）。篩選只影響清單，摘要固定顯示整月。
- **分組清單**：日期降冪，每天一組，標題「10 月 23 日（四）」與當日支出／收入小計；每列：圖示（類別圖示；轉帳用轉帳圖示）、主文字（類別名；轉帳為「從 → 到」）、次文字（帳戶、備註）、金額（支出紅、收入綠、轉帳灰）。
- **列操作**：點列開啟編輯；列尾選單有「複製」「刪除」。
- **批次模式**：「選取」按鈕進入多選，列前出現核取方塊，底部出現「刪除選取的 N 筆」（需確認）。
- **空狀態**：當月沒有交易時顯示提示與「記一筆」按鈕。
- **效能**：一次抓整月（通常數百筆以內），查詢鍵 `['entries', ledgerId, month]`。

## 資料存取

- 查詢：`entries` 依 `ledger_id` 與月份範圍，`kind <> 'opening'`，依 `entry_date desc, created_at desc`；科目名稱與圖示由已快取的 accounts 對應，不另外 join。
- 寫入：`save_entry(p_entry, p_lines)`，分錄行由 `buildLines` 產生，更新時帶 `id`；資料庫端 trigger 再檢查一次借貸平衡。
- 刪除：直接 `delete from entries`（RLS 保護；分錄行 cascade）。
- 寫入或刪除後 invalidate：該月 entries、balances、openings；帳戶頁與之後的報表因此即時更新。
- 本里程碑**不需要新 migration**。

## 驗收

- Vitest：算式（四則、括號、小數、非法輸入、除以零、前導零）、既有 posting 測試。
- 瀏覽器：記支出／收入／轉帳各一筆 → 帳戶頁餘額對應變動；編輯金額 → 餘額更新；刪除 → 餘額還原；月份切換；篩選與搜尋；複製；批次刪除；「再記一筆」保留日期與帳戶。
- SQL：以 RPC 送不平衡分錄被拒（既有測試）；交易刪除後 `account_balances` 正確。
- lint／test／build 通過，CI 綠燈，正式站實測。
