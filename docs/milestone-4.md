# 里程碑 4：筆記本體驗與視覺化 — 規格

討論日期：2026-10-23（取代原路線圖的「儀表板圖表」，並併入 UI 調整）。

使用者的核心用意：**打開就看懂今天存多少、花多少、比昨天多存多少、哪裡花過頭**。討厭手寫帳本的麻煩，也討厭記帳 app 付費解鎖，所以這個平台要「像一本好看的筆記本，但數字由系統算」。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 整體隱喻 | 帳本是一本獨立的筆記本：封面 → 翻開 → 一天一頁的內頁；頂部分頁通往附錄（交易、帳戶、類別、報表、設定） |
| 封面 | 手寫字的帳本名稱、個人標語；封面顏色與材質可選（布面、皮面、牛皮紙等，搭配主題色） |
| 翻書動畫 | 登入後進入帳本時播一次，可跳過；同一次使用中切換頁面不再播；尊重系統「減少動態」設定 |
| 內頁質感 | 細微紙紋 + 淡格線，數字與圖表保持清晰；深色模式用深色紙 |
| 首頁 | **一天一頁**：翻開落在今天；左右翻頁（鍵盤左右鍵、手機滑動）+ 日曆彈窗跳日（有記帳的日子有小點） |
| 日頁內容 | 日期手寫標題、今日收入／支出／結餘三個大數字與筆數、與昨天及上週同一天的比較（「今日結餘」與「淨值」兩種都顯示）、個人標語、警示區、當天交易清單（可點編輯）、記一筆 |
| 月章節頁 | 每個月的第一頁：近 30 天每日收支長條、本月支出類別環圈、本月累計；點圖表從右側滑出明細面板（與報表下鑽相同） |
| 年度總覽 | 當作封底：12 個月收支、淨值走勢、年度類別占比與重點數字 |
| 三張報表 | 保留為附錄頁，版面依 UI 回饋簡化（見下） |
| 花過頭的尺 | 類別頁直接填「每月基準線」；本月花錢速度換算整月超過基準線 30% → 紅色警示；過去三個月平均超過基準線 30% → 橙色「習慣性超支」提醒；單筆大額也提醒 |
| 警示呈現 | 列出類別、超出金額與一句建議，例如「飲食照目前速度整月會花 $9,800，超過基準線 $7,500；剩 12 天建議每天 $250 內」。沒有警示時顯示「今天很乖」 |
| 存錢動畫 | 硬幣掉進撲滿、撲滿微晃、數字滾到新結餘；觸發時機：記一筆收入、轉帳到儲蓄或投資帳戶 |
| 支出動畫 | 一般花費只蓋「已記」印章 + 類別圖示跳一下；觸發警示時改播紙鈔飛走、印章變橙並附一句提醒 |
| 動畫原則 | 每段 ≤ 1.2 秒；設定頁可關閉；「減少動態」時改成靜態印章；不新增重量級動畫套件（CSS 關鍵影格 + Web Animations API + SVG） |
| 實作順序 | 先外殼再內容，四個 PR，每個都能上線使用（見「PR 切分」） |

## UI 微調（併入本里程碑，對應使用者的三個不滿意點）

- **手帳元素少即是多**：統計卡拿掉紙膠帶改細漸層上緣線；印章只用在「淨值」「平衡」「已記」三種語意；便利貼日期、波浪底線、清單卡中間的打孔缺口拿掉；收據鋸齒邊只留在記帳與明細面板；圓角與陰影統一。
- **漸層只用在重點**：標誌字、主要按鈕、頂部目前分頁；其餘用主題色單色墨或淡底。紙底改細微紙紋的淺暖灰、卡片純白、對比拉高；收入綠與支出紅稍微提亮；深色模式同步。
- **報表像一張正式但好讀的報表**：區段標題改粗體小字 + 細線；表格欄位標題固定、列高一致、hover 淡底；「佔收入 %」旁加細比例條；摘要卡簡化；檢核列平衡時一行淡綠提示 + 小印章；明細面板標題精簡、列表樣式與交易頁統一。

## 「花過頭」計算規則

- **基準線**：`accounts.monthly_budget`（每月金額，只對費用類別有意義；子類別可各自填，父類別的基準線含子類別）。
- **紅色警示（本月速度）**：預估整月 = 本月至今支出 ÷ 已過天數 × 當月天數；預估整月 > 基準線 × 1.3 才警示。本月至今不足 3 天或該類別本月不足 2 筆時不預估（避免 1 號一筆就被罵）。
- **橙色提醒（習慣性超支）**：過去三個完整月的平均月支出 > 基準線 × 1.3。
- **沒填基準線的類別**：用過去三個完整月的平均當基準線，只做紅色預估檢查；沒歷史也沒基準線就不警示。
- **單筆大額**：一筆 > 該類別過去 90 天平均單筆 × 3，且歷史至少 5 筆；記帳後立刻提醒，並列入當日警示區。
- 建議句的「每天建議金額」= max(0, 基準線 − 本月至今) ÷ 剩餘天數。
- 計算放在資料庫函式 `category_spending_stats(p_ledger, p_month)` 回傳每個費用類別的：本月至今、本月筆數、過去三個月平均、過去 90 天平均單筆與筆數、基準線；判斷邏輯放前端純函式（Vitest）。

## 資料庫變更（新 migration）

- `accounts.monthly_budget numeric(14,2) null`：每月基準線。
- `accounts.subtype` 多一個值 `savings`（儲蓄，資產；欄位是自由文字，只需在前端 `SUBTYPES` 加上）；現金流量表維持只把 cash／bank／ewallet 當現金，轉到儲蓄帳戶會列在投資活動。
- `ledgers.cover_color text`、`ledgers.cover_material text`（預設值由前端決定）。
- `profiles.animations_enabled boolean not null default true`。
- `daily_summary(p_ledger, p_from, p_to)`：每日收入、支出、筆數（日頁與 30 天長條共用）。
- `category_spending_stats(p_ledger, p_month)`：見上。
- 淨值與昨天比：沿用 `report_balance_sheet` 查兩個日期。
- 全部 `security invoker`、`set search_path = ''`，只授權 `authenticated`。

- 報表期間選擇器改成「月／季／年／自訂」分段按鈕 + 上一期／下一期，拿掉下拉選單。
